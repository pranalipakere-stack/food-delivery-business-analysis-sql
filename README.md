# Food Delivery Business Analysis using SQL

## Project Overview
This project focuses on analyzing a food delivery business dataset using MySQL. The objective is to understand business operations by exploring orders, customers, restaurants, riders, and delivery information.

I am building this project step by step while improving my SQL skills through daily practice, starting with basic queries and gradually moving towards advanced SQL concepts.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Dataset Overview

The project contains five tables:

| Table | Description |
|---|---|
| customers | Customer registration details |
| orders | Order information and transaction amounts |
| restaurants | Restaurant names, cities, and opening hours |
| riders | Rider registration details |
| deliveries | Delivery status, time, and rider information |

**Total records:** 20,600

## SQL Topics Covered

1. SELECT statements
2. WHERE conditions
3. ORDER BY and LIMIT
4. Aggregate functions
5. GROUP BY
6. INNER JOIN
7. LEFT JOIN
8. Subqueries
9. Common Table Expressions (CTEs)
10. Window Functions

## Daily SQL Practice

I am using this project for daily SQL practice. I started with very easy, beginner-level questions to build a strong foundation and improve my confidence.

My practice approach:

- Solve simple SQL questions regularly.
- Understand each query instead of memorizing it.
- Practise filtering, sorting, and aggregation.
- Learn joins with practical examples.
- Gradually move towards subqueries, CTEs, and window functions.
- Review and improve previously written queries.

The goal is to improve step by step, from beginner-level SQL to the skills required for a Data Analyst role.
